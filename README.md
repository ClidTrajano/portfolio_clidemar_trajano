# Portfólio Clidemar Trajano

Site estático em HTML, CSS e JavaScript, pronto para publicação no GitHub Pages.

## Publicar no GitHub Pages pelo navegador

1. Crie um repositório no GitHub.
2. Envie todos os arquivos desta pasta para a raiz do repositório.
3. No repositório, acesse `Settings > Pages`.
4. Em `Build and deployment`, selecione `Deploy from a branch`.
5. Escolha a branch `main` e a pasta `/root`.
6. Salve. O GitHub vai gerar um link público em alguns minutos.

O arquivo inicial do site é `index.html`.
